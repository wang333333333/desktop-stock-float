# 悬浮股价 · Windows 桌面行情小窗

免安装的 A 股实时行情悬浮窗。单文件 PowerShell 脚本，双击即用，不写注册表、不起后台服务、不安装任何运行时。

## 特性

| 能力 | 说明 |
| --- | --- |
| 零依赖 | 仅用 Windows 自带的 PowerShell 5.1 + WinForms，无需 Python / Node / .NET 安装 |
| 免安装 | 解压即用，绿色便携，删除文件夹即卸载 |
| 实时刷新 | 交易时段默认 1 秒一次，非交易时段完全停止请求 |
| 无边框置顶 | 半透明悬浮窗，可拖动、可缩放、位置自动记忆 |
| 自选管理 | 右键添加 / 移除任意 A 股，列表自动持久化 |
| 深浅主题 | 顶栏一键切换 |
| 本地运行 | 数据直连行情源，不经任何中转，无统计、无上报 |

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| 运行时 | Windows PowerShell 5.1（系统内置） |
| 权限 | 普通用户，无需管理员 |
| 占用 | 磁盘 < 1 MB；内存 30–60 MB |

macOS / Linux 不支持（依赖 WinForms）。

## 快速开始

```bash
git clone https://github.com/wang333333333/desktop-stock-float.git
cd desktop-stock-float
```

1. 将文件夹解压或克隆到**有写权限**的目录（桌面、D 盘等）。不要放在 `C:\Program Files`，否则状态文件无法写入。
2. 双击 `启动悬浮股价.vbs`，无控制台窗口，浮窗直接显示。
3. 首次启动为空白状态，点击卡片或右键菜单输入 6 位股票代码即可添加。

若双击无响应，改用 `启动悬浮股价.bat`，控制台会输出具体错误。

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动标题栏 / 空白区 | 移动窗口，位置自动记忆 |
| 顶栏 `—` / `×` | 最小化 / 关闭 |
| 顶栏圆点 | 深色、浅色主题切换 |
| 拖拽右下角 | 调整窗口尺寸 |
| 右键 → 添加自选… | 输入 6 位代码，回车添加 |
| 右键 → 移除该股 | 删除当前股票 |
| 右键 → 取消置顶 | 允许被其他窗口覆盖（再点一次恢复） |
| 右键 → 大小 | 缩放 70%–180% |
| 右键 → 透明度 | 多档可调 |
| 右键 → 刷新频率 | 自动 / 1 秒 / 2 秒 / 5 秒 / 暂停 |
| 右键 → 立即刷新 | 立即请求一次数据 |
| 右键 → 退出 | 结束进程 |

## 股票代码

输入 6 位数字，自动识别交易所：

| 首位 | 市场 | 示例 |
| --- | --- | --- |
| 6 / 9 / 5 | 上交所 | 600519、601318、510300 |
| 0 / 1 / 3 | 深交所 | 000001、300750 |
| 4 / 8 | 北交所 | 430047 |

也支持带前缀写法：`sh600519`、`sz000001`、`bj430047`。

当前仅支持 A 股（沪 / 深 / 北），不支持港股、美股。

## 数据与刷新机制

- **交易时段**（9:30–11:30、13:00–15:00）：默认 1 秒一次请求。该频率已是公开接口上限，行情源本身存在数秒延迟。
- **非交易时段**（午休、收盘、周末、节假日）：完全停止请求，状态栏显示「午休 / 未开盘 / 已收盘」，不产生任何网络流量。
- 状态栏右侧时间戳为本机最后一次成功取数的时间（`HH:mm:ss`）。
- 行情来源为腾讯财经公开接口 `qt.gtimg.cn`，免费、无需账号或密钥。数据归属原服务方，本项目不缓存、不转发。

## 文件结构

```
desktop-stock-float/
├── stock_float.ps1        主程序（WinForms 界面 + 行情解析）
├── 启动悬浮股价.vbs       静默启动器，推荐
├── 启动悬浮股价.bat       带控制台的启动器，用于排查
├── README.md
└── LICENSE
```

运行时会在同目录生成三个状态文件，删除后恢复默认值：

| 文件 | 内容 |
| --- | --- |
| `.float_pos.json` | 窗口位置、尺寸、主题、透明度、刷新频率 |
| `.float_watch.json` | 自选股列表 |
| `.float_err.log` | 异常日志（仅出错时写入） |

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击 VBS 无反应 | 安全软件启发式拦截「VBS 静默调用 PowerShell」 | 将目录加入信任区，或改用 `.bat` 启动 |
| 提示「禁止运行脚本」 | 组策略限制执行策略 | 优先用 `.bat`（带 `-ExecutionPolicy Bypass`）；仍失败需管理员调整策略 |
| 窗口不可见 | 坐标超出显示器范围 | 删除 `.float_pos.json` 后重新启动 |
| 自选股全部消失 | `.float_watch.json` 被删除或损坏 | 重新添加即可 |
| 需要开机自启 | — | `Win+R` → `shell:startup`，将 VBS 快捷方式放入该目录 |
